# MaxMind DB test files

These databases come from the `test-data` directory of
[maxmind/MaxMind-DB](https://github.com/maxmind/MaxMind-DB), downloaded on 2026-10-19:

- `MaxMind-DB-test-mixed-24.mmdb`: IPv4 and IPv6 networks in an IPv6 tree, with the IPv4 aliases.
- `GeoIP2-Country-Test.mmdb`: a small GeoIP2 Country database.
